# The Foundations Behind the Gestural Transformation of Sound

DSC 180 Capstone, UC San Diego · Sahar Zahir · Mentor: Victor Minces

**Live site:** https://saharzahir.github.io/VibeCode-Practice/

## About

This project builds the foundation for an instrument that turns gestures into sound. It is a set of browser-based tools for exploring how sound is made from a fundamental frequency and its harmonics, and how the amplitudes of those harmonics create timbre and vowels.

- **Partials Lab** (`index.html`) builds sounds from lists of frequencies and amplitudes and shows each one as a waveform and a spectrum. It can record your voice and rebuild it from its harmonics, shape sounds into vowels with filters, and be played with sliders, a touch pad, phone tilt or a camera.
- **Morph Lab** (`morph.html`) records several sounds and blends smoothly between them as you drag across a line or a square.

## How to run

Open the live site above in Chrome or Safari. No installation is needed. To run it locally, download this repo and open `index.html` in a browser. The microphone and camera require a secure page, so they work on the live site or from a local file, and the browser will ask for permission.
